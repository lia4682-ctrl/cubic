이미지 업로드

이미지를 첨부하고 이름·태그를 적으면 GitHub 저장소에 자동으로 커밋돼요. 커밋되면 연결된 호스팅이 사이트를 다시 배포합니다.

1. GitHub 연결

index.html이 저장소 안 하위 폴더에 있을 때만 적어요.
이 저장소 하나에만 Contents: Read and write 권한을 준 토큰을 쓰세요.
토큰을 안전하게 쓰는 법
  • 토큰은 이 페이지에서 api.github.com 으로만 전송돼요. 다른 곳으로 보내지 않아요.
  • 이 페이지는 사이트와 함께 공개되지만, 토큰이 없는 사람은 아무것도 올릴 수 없어요.
  • 공용 PC에서는 “기억하기”를 끄세요. 토큰에는 만료일을 꼭 지정하고, 유출이 의심되면 GitHub에서 바로 폐기하세요.
